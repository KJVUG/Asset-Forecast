# 收入趋势复盘与个人资产预测器

一个单文件、零依赖的个人财务推演工具。打开网页即用，所有数据只存在你自己的浏览器里。

**在线使用 → https://kjvug.github.io/Asset-Forecast/**

## 它做什么

把「现在赚多少、花多少、存下多少」推演成「十年后是什么样」，并把结果落到可执行的判断上。

| 模块 | 内容 |
|---|---|
| 01 收入复盘 | 逐月记录固定收入、浮动收入、副业与被动收入，观察结构变化 |
| 02 预测器 | 按增长率、通胀、投资回报推演未来十年资产曲线（含压力情景） |
| 03 目标存款 | 设定目标金额与期限，反推「每月要存多少」，并给出按期概率 |
| 04 等级与优化 | 六档财务等级定位、四项体检、资产结构诊断与再平衡建议 |
| 05 年度明细 | 逐年拆解资产构成，查看复利与结余各自的贡献 |
| 06 账单分析 | 导入账单、按分类规则聚合，回答「钱花在哪了」 |

## 数据与隐私

- 全部计算在浏览器本地完成，**没有任何后端请求，数据不上传**。
- 数据保存在 `localStorage`（键名前缀 `assetPredictorV2`），清除浏览器数据即丢失，建议定期用页面内的导出功能备份。
- 换浏览器、换域名、或无痕模式打开，都会是一份全新的空白数据。
- 因此这也是一个可以放心用真实收入去填的工具 —— 只要你在用自己信任的那台设备。

## 本地运行

不需要安装任何东西、不需要构建：

```bash
# 直接双击 index.html，或起一个静态服务
python -m http.server 8000
# 打开 http://localhost:8000
```

## 技术说明

- 单个 HTML 文件（约 360 KB），CSS 与 JavaScript 全部内联，无外部 CDN、无字体依赖，断网可用。
- 图表为手写 Canvas 绘制，不依赖图表库。
- 支持亮 / 暗两套主题，适配移动端。
